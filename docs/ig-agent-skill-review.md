# 인스타 스킬 13개 검토와 카드뉴스 적용 설계

2026-11-07 · 대상: [Jakeschincariol/instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) (커밋 `d03c56b`, MIT)
· 노션 안내 페이지 "잘나가는 계정들이 몰래 쓰는 인스타 스킬 13가지"

## 결론

- **그대로는 못 씁니다.** 이 스킬 13개는 영어 계정을 기준으로, 사람이 직접 올리는 흐름을 전제로 만들어졌습니다. 우리 자동 게시 작업에 그대로 넣으면 두 가지가 깨집니다.
  - **한국어 처리.** 실제 캡션으로 돌려 보니 한글 해시태그를 못 세고, 가운뎃점(·)을 하이픈으로 바꿔 버립니다.
  - **자동 게시.** 스킬마다 "사용자가 승인해야 만든다, 게시는 사용자가 한다"고 적혀 있어서 자동 게시와 부딪힙니다.
- **쓸 만한 것은 규칙과 지표입니다.**
  - 캡션 규칙: 해시태그 5개, 첫 줄, 행동 유도 하나, 검색어, 링크 금지
  - 글자 정리: 보이지 않는 문자, 줄표(—)
  - 캐러셀 원칙: 2장과 마지막 장
  - 성과 점검 지표: 계정 중앙값 대비 배수, 도달당 저장·공유
- **이번에 적용한 것:** `engine/caption.mjs`를 새로 만들고, `GUIDE.md`의 5·7·8절과 맨 위 안내를 고쳤습니다.
- **승인이 필요한 제안:** 주간 성과 점검 작업, 월간 경쟁 계정 비교.

## 설치 상태

- 이 클라우드 세션의 `~/.claude/skills`에 13개를 모두 설치했고, 세션에 등록된 것까지 확인했습니다. 다만 세션이 끝나면 사라집니다.
- 저장소의 `.claude/skills`에는 **일부러 넣지 않았습니다.** 매시간 작업이 "캐러셀", "캡션" 같은 말에 반응해 스킬을 스스로 불러올 수 있습니다. 그러면 "승인 후 제작", "6~10장", "해시태그 3개" 같은 규칙이 GUIDE.md와 섞입니다.
- 연님이 대화에서 계속 쓰려면 둘 중 하나로 설치하시면 됩니다.
  - claude.ai: 맞춤 설정 → 스킬 → 스킬 업로드 (노션 안내 2단계와 같습니다)
  - PC의 Claude Code: `/plugin marketplace add Jakeschincariol/instagram-agent-skill` 다음에 `/plugin install instagram-agent`

## 안전 점검

- 파일 27개(183KB)를 설치 전에 모두 읽었습니다.
- 파이썬 도구 6개는 표준 라이브러리만 씁니다. 네트워크 접속이나 외부 명령 실행은 없고, 입력 파일을 읽어 결과 파일만 씁니다.
- 지시문에는 로그인·대량 수집·자동 댓글·자동 DM을 하지 말라는 규칙만 있고, 위험한 지시는 없습니다.

## 실제 게시물로 시험한 결과

시험 대상: @yeon.virel 캡션 5개와 표지 제목 3개.

| 도구 | 결과 | 판정 |
|---|---|---|
| `ig-caption/caption.py` | 한글 해시태그를 못 세고(`#LH`, `#SK`만 셈), "11월 13일" 같은 숫자와 "공유해 주세요" 같은 행동 유도를 인식하지 못함 | 도구는 못 씀. **규칙만** 가져옴 |
| `ig-human/humanize.py` | 가운뎃점(·)을 하이픈으로 바꿔 "경·공매"가 "경-공매"가 됨. 화살표 →도 `->`로 바꿈 | 한국어를 망가뜨림. **보이지 않는 문자·줄표·둥근 따옴표 처리만** 가져옴 |
| `ig-human/detect.py` | 단어 단위로 세서 한국어 캡션은 "too short to judge" | 쓸모 없음 |
| `ig-reel/hookscore.py` | 우리 표지 3개 모두 38~43점(WEAK), 영어 예시는 85.6점(STRONG) | 영어 단어 기준이라 한국어는 평가 불가. 저자도 잘된 훅을 고르는 정확도가 AUC 0.56(동전 던지기 수준)이라고 밝힘 |
| `ig-carousel` 지시문 | 1080×1350 크기, 쪽 번호(n / t), 각 장 핸들 표시 | 우리 엔진이 이미 함. 2장·마지막 장 원칙만 추가 |

캡션 5개 모두 해시태그가 7~9개였습니다. 인스타 상한(5개)을 넘었고, 새 검사였다면 다섯 건 모두 게시 전에 막혔을 것입니다.

## 이번에 적용한 변경

- **`engine/caption.mjs`** (새 파일. `publish.mjs`가 게시 전에 부름)
  - 자동 정리:
    - 보이지 않는 문자는 지우고, 줄바꿈 없는 공백은 일반 공백으로 바꿈
    - 줄표(—)는 쉼표, 둥근 따옴표는 곧은 따옴표, 말줄임표(…)는 `...`
  - 정리하지 않고 그대로 두는 것:
    - 가운뎃점(·), 화살표(→)
    - ✔️ 같은 이모지에 필요한 보이지 않는 문자(U+200D, U+FE0F)
  - 게시를 멈추는 경우:
    - 500자 초과(쓰레드 방식으로 셈): 종료 코드 5
    - 해시태그 6개 이상 또는 링크 있음: 종료 코드 6
  - 경고만 하는 경우: 첫 줄이 70자 넘음, 첫 줄에 숫자 없음, 첫 줄이 해시태그나 이모지로 시작
- **`GUIDE.md`**
  - 7절(캡션): 해시태그 3~5개, 첫 문장 앞쪽에 핵심 숫자, 행동 유도 하나, 검색어를 본문에 넣기, 줄표 금지
  - 5절(슬라이드): 2장은 표지 없이 봐도 이해되게, 마지막 장은 캡처해서 보내도 혼자 통하게
  - 8절(게시): 종료 코드 6의 뜻, `node engine/caption.mjs posts/<id>`로 미리 검사하는 법
  - 맨 위 안내에 ④ 해시태그 5개 이하 추가
- **시험**
  - 오염시킨 예시 문장으로 돌려서 BOM·폭 없는 공백·줄바꿈 없는 공백·줄표·둥근 따옴표·말줄임표가 정리되는 것을 확인했습니다.
  - 같은 예시에서 ·, →, ✔️는 그대로 남았습니다.
  - 해시태그 7개 캡션은 종료 코드 6, 510자 캡션은 종료 코드 5로 커밋 전에 멈췄습니다.

확인이 덜 된 부분:
- 피드에 보이는 캡션 길이: 영어는 약 125자인데, 한글이 몇 자까지 보이는지는 확인하지 못했습니다. 경고 기준 70자는 추측입니다.
- 쓰레드 해시태그: 쓰레드는 게시물당 태그 1개만 인식한다고 합니다. 5개를 넣으면 그중 어느 것이 태그가 되는지는 확인하지 못했습니다.
- 2장 다시 보여주기: "첫 장에 반응하지 않은 사람에게 2장부터 다시 보여준다"는 스킬의 주장이고, 인스타 공식 문서로 확인하지는 않았습니다.

## 제안 1: 주간 성과 점검 (ig-audit 방식, 승인 필요)

- **시기:** 매주 월요일 오전. 게시물이 30개쯤 쌓여야 의미가 있습니다. 지금은 6개라, 그 전에는 "판단 보류"로만 기록합니다.
- **데이터:** Metricool 분석 도구에서 게시물별 도달, 저장, 공유, 비팔로워 도달 비율. 실제로 받을 수 있는 지표는 먼저 확인해야 합니다(아직 확인 안 함).
- **볼 지표:** 계정 중앙값 대비 배수, 도달당 저장, 도달당 공유, 비팔로워 도달 비율. 원시 조회수로는 순위를 매기지 않습니다.
- **결과물:** `state/audit.md`. 예를 들어 저장이 많이 나오는 분야를 찾아 GUIDE 2절의 점수표를 조정하는 근거로 씁니다. 지침 변경은 연님 확인 후에만 합니다.
- **위험:** 표본이 적을 때 잘못된 결론을 낼 수 있습니다. 그래서 몇 개를 보고 판단했는지를 항상 같이 적습니다.

## 제안 2: 월간 경쟁 계정 비교 (ig-viral 방식, 승인 필요)

- **대상:** 국내 뉴스 카드 계정 6~12개(직접 경쟁 4, 인접 분야 4, 대형 2~4). 계정은 연님이 정해 주셔야 합니다.
- **방법:** vidIQ의 인스타 아웃라이어 검색으로, 각 계정의 중앙값보다 훨씬 잘된 게시물을 찾아 표지 문구 유형을 정리합니다.
- **원칙(스킬 규칙 그대로):** 로그인 대행과 대량 수집은 하지 않습니다. 형식만 참고하고, 문구와 디자인은 베끼지 않습니다.

## 하지 않기로 한 것

- **스킬을 저장소 `.claude/skills`에 그대로 넣기:** 위 "설치 상태"에 적은 이유 때문입니다(자동 호출, 승인 게이트, 규칙 충돌).
- **훅 점수기로 표지 검수:** 한국어를 평가하지 못합니다.
- **슬라이드를 6~10장으로 늘리기:** 스킬 저자의 의견일 뿐 근거가 없습니다. 뉴스 요약에는 4장 안팎이 맞을 수도 있지만 이것도 추측입니다. 주간 점검 데이터가 쌓이면 판단합니다.
